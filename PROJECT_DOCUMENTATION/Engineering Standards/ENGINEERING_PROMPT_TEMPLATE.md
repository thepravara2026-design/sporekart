## Usage Rules

1. This template is **mandatory** for every future sprint prompt.
2. Fill every field before beginning work.
3. The `Commit`, `Push`, and `Merge` fields must always read `ONLY AFTER USER APPROVAL`.
4. The `Manual Review Required` field must always read `YES`.
5. Do not remove or reorder any field.
6. Attach this template to the sprint record in `PROJECT_DOCUMENTATION/Sprint Reports/`.
