# Batch Analytics

Batch comparison with at-risk student tracking.

## Sections

1. **Batch Cards** — Per-batch display with total/active/at-risk metric cards, completion progress ring, and 4 sub-metrics
2. **Comparison Charts** — Batch completion rate bar chart + at-risk students bar chart

## Features

- Red metric card for at-risk count
- Dual chart comparison for quick batch health assessment
- At-risk bar chart highlights batches needing attention
