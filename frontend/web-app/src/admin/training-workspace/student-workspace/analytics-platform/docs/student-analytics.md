# Student Analytics

Per-student performance analysis with aggregated metrics and filtering.

## Sections

1. **Summary Metrics** — Avg Attendance, Avg Assignment, Avg Assessment, Avg Progress
2. **Progress Rings** — Top 6 students' learning progress rings with color coding
3. **Performance Table** — Sortable table with columns: Student, Course, Attendance, Assignment, Assessment, Progress, Performance Level, Risk
4. **Filters** — Course, batch, performance level dropdowns + search bar

## Features

- Empty state with "Clear Filters" when search/filter yields no results
- Color-coded risk indicators (high/medium/low)
- Performance level labels mapped from types.ts constants
