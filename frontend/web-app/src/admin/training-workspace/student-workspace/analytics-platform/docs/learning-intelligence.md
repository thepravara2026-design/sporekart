# Learning Intelligence

Deep learning analytics with health monitoring, competency analysis, and forecasts.

## Sections

1. **Learning Health** — 4 health indicators with color-coded circular badges (healthy=green, warning=yellow, critical=red)
2. **Competency Analysis** — Radar chart of competency categories vs max levels
3. **Achievement Distribution** — Pie/donut chart by achievement type
4. **Forecasts** — Completion + certification forecast line charts (predicted vs actual)
5. **Engagement Analysis** — 8 student engagement tiles with trend direction (improving/stable/declining)
6. **Performance Analysis** — 4 student score breakdowns with ScoreCard bars

## Features

- Radar chart for multi-dimensional competency visualization
- Engagement trend detection with directional arrows
- Dual forecast charts for completion and certification predictions
