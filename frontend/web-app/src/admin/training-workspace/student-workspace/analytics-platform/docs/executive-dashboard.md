# Executive Dashboard

An enterprise KPI overview with top-level metrics and trends.

## Sections

1. **KPI Row** — 8 KPI tiles (Active Students, Total Courses, Active Trainers, Active Batches, Completion Rate, Avg Attendance, Avg Assessment, Certification Rate) each showing change vs previous month
2. **Summary Metrics** — 8 MetricCard components with icon variants
3. **Trend Charts** — Enrollment & Completion line charts over 12 months
4. **Recent Activity** — Timestamped platform activity feed
