# Course Analytics

Course-level metrics and cross-course comparison.

## Sections

1. **Course Cards** — Scored cards per course showing enrollment count, completion count, progress ring, and 4 sub-metrics (attendance, assignment, assessment, certification)
2. **Trend Charts** — Enrollment vs Completion line charts per course
3. **Assessment Distribution** — Bar chart per course showing score range distribution

## Features

- Responsive grid 220px min-width
- ProgressRing for completion percentage per course
- Assessment results bucketed into score ranges
