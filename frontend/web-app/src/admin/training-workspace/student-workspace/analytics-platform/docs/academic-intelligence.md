# Academic Intelligence

Deep academic insights with risk detection and learning gap analysis.

## Sections

1. **Summary Cards** — Top Students, High Performers, Needs Attention, Attendance Risks, Completion Risks counts
2. **Performer Tables** — Top performers (5 rows) + needs attention (5 rows) with full metrics
3. **Trend Chart** — Achievement completions over time (line chart)
4. **Learning Gaps** — Bar chart showing skills with most students affected
5. **Risk Tables** — Attendance risks + completion risks detail tables

## Features

- Dual table layout for immediate comparison of high vs low performers
- Color-coded risk indicators
- Learning gaps identified by skill name and affected student count
