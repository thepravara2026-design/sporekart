# Trainer Analytics

Trainer effectiveness metrics and comparison.

## Sections

1. **Trainer Cards** — Per-trainer display with students/courses metric cards, success rate progress ring, and 4 sub-metrics (attendance, assessment, completion, certification)
2. **Comparison Chart** — Bar chart comparing trainer success rates

## Features

- MetricCard for quick stats per trainer
- ProgressRing for student success rate visualization
- Horizontal bar chart for cross-trainer comparison
