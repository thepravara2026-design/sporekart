# Communication Platform — Announcement Architecture

## Overview

The Announcement Center manages organization, course, batch, trainer, academic alert, holiday, system maintenance, emergency, and government announcements with full lifecycle tracking.

## Categories

| Category | Description |
|---|---|
| organization | Enterprise-wide announcements |
| course | Course-specific announcements |
| batch | Batch-level announcements |
| trainer | Trainer-originated announcements |
| academic-alert | Academic integrity/performance alerts |
| holiday | Holiday schedule notices |
| system-maintenance | Platform maintenance notifications |
| emergency | Urgent emergency communications |
| government | Government/regulatory notifications |

## Features

- Category filter tabs
- Status tracking (draft → scheduled → sent → delivered → expired)
- View count tracking
- Attachment count indicator
- Scheduled date and expiry date support
