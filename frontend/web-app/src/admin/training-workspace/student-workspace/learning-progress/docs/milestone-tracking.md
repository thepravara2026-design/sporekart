# Learning Progress Platform — Milestone Tracking

## Overview

Milestones track key achievements throughout the learning journey: course started, 25%/50%/75%/100% progress, assignment/assessment/attendance/competency milestones, certification readiness, and course completion.

## Milestone Types (11)

| Type | Description |
|------|-------------|
| `course-started` | Student began the course |
| `progress-25` | Reached 25% completion |
| `progress-50` | Reached 50% completion |
| `progress-75` | Reached 75% completion |
| `progress-100` | Reached 100% completion |
| `assignment-milestone` | Assignment submission milestone |
| `assessment-milestone` | Assessment milestone |
| `attendance-milestone` | Attendance threshold reached |
| `competency-milestone` | Competency level achieved |
| `certification-ready` | Eligible for certification |
| `completed` | Course fully completed |

## Visualization

- **MilestoneCenterPage**: Grid of MilestoneCard components with type and achieved/pending filters
- **MilestoneCard**: Shows type, description, course, achieved date, green/pending styling
