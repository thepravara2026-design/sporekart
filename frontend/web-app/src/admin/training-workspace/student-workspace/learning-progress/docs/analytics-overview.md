# Learning Progress Platform — Analytics Overview

## Overview

The Learning Analytics module provides quantitative insights into learning progress, completion rates, and student engagement patterns.

## Analytics Dimensions

| Dimension | Description |
|-----------|-------------|
| Course Completion | Percentage of courses completed |
| Module Completion | Percentage of modules completed |
| Lesson Completion | Percentage of lessons completed |
| Average Learning Hours | Mean learning hours across all students |
| Assessment Success Rate | Percentage of assessments passed |
| Assignment Success Rate | Percentage of assignments submitted |
| Competency Growth | Competency development rate |

## Visualizations

### Progress Distribution
Bar chart showing student count across 4 ranges: 0–25%, 26–50%, 51–75%, 76–100%

### Monthly Active Students
Bar chart showing student activity across Jan–Jun with counts on each bar

### Summary Widgets
6 stat widgets in the AnalyticsPanel component:
- Course Completion (default)
- Module Completion (blue)
- Assessment Success (green)
- Assignment Success (yellow)
- Avg Learning Hours (default)
- Competency Growth (green)
