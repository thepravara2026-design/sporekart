# Learning Progress Platform — Dashboard & Health Monitoring

## Overview

The Learning Health Dashboard provides a real-time snapshot of overall learning ecosystem health with 11 key metrics and drill-down summaries.

## Dashboard Widgets (11)

| Widget | Variant | Description |
|--------|---------|-------------|
| Total Students | default | All enrolled students |
| On Track | success | Students progressing normally |
| Behind Schedule | danger | Students falling behind |
| Average Progress | info | Mean progress % across all courses |
| Completion Rate | success | Course completion percentage |
| Attendance Health | success/warning | Overall attendance % |
| Assignment Completion | info | Assignment submission rate |
| Assessment Completion | success/warning | Assessment evaluation rate |
| Competency Coverage | info | Skills coverage percentage |
| Total Learning Hours | default | Cumulative learning hours |
| At Risk | danger | Students behind schedule |

## Health Metrics Panel

Shows detailed breakdown of:
- Student Status (on track, behind, at risk counts)
- Health Metrics (attendance, assignments, assessments, competency percentages)

## Color Coding

- Green (success): Metrics ≥ 75%
- Blue (info): Metrics 50–74%
- Yellow (warning): Metrics 30–49%
- Red (danger): Metrics < 30%
- Default: Neutral metrics
