# Alumni Domain Model

## Engagement Levels
`active` | `moderate` | `low` | `disengaged` | `lifetime` | `ambassador` | `mentor` | `donor`

## Key Interfaces
- **AlumniProfile** — Full alumni profile with company, position, batch, engagement, mentorship status
- **AlumniMentorship** — Mentor-mentee pairing with focus area, sessions, rating
- **AlumniContribution** — Monetary, equipment, mentorship hours, guest lectures, etc.
- **AlumniEvent** — Networking, workshops, webinars, reunions, hackathons, etc.
- **AlumniAnalytics** — Aggregated metrics, trends, distribution charts

## Pages
- AlumniDirectory — Searchable directory with engagement level tabs
- AlumniMentorship — Mentorship pair list with active/completed/paused tabs
- AlumniEvents — Event lifecycle with upcoming/open/completed tabs
- AlumniContributions — Contribution records with type tabs
