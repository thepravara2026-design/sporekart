# Analytics Architecture

## Data Sources
- StudentCareerProfiles (placement status, scores)
- AlumniProfiles (engagement, batch, industry, location)
- Mentorships (active, completed, hours, ratings)
- Contributions (count, value, type)
- Events (registration, attendance)
- PlacementDrives (stage, registrations, selections)

## Computed Metrics
- **AlumniAnalytics** — Total/active/engaged alumni, mentors, contributions, events, placement rate, salary, trends by month, distribution by batch/industry/location
- **PlacementDashboard** — Student counts by status, active drives, jobs, partners, packages, top recruiters

## Pages
- PlacementAnalytics — Comprehensive dashboards with placement progress ring, monthly trends, top recruiters, alumni distribution charts
