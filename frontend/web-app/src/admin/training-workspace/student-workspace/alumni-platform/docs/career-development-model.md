# Career Development Domain Model

## Career Stages
`exploration` | `skill-building` | `resume-preparation` | `interview-preparation` | `job-search` | `placement` | `post-placement` | `alumni` | `mentorship` | `lifelong-learning`

## Key Interfaces
- **StudentCareerProfile** — Complete career profile with scores, skills, objectives, offers
- **CareerCounselingSession** — One-on-one or group counseling sessions
- **InterviewPreparation** — Per-round interview tracking with company, type, result
- **SkillGapAssessment** — Current vs required skill levels with priority

## Pages
- CareerDevelopmentCenter — Unified page with 4 tabs: Career Profiles, Counseling, Interview Prep, Skill Gaps
