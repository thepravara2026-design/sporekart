# Company Partnership Domain Model

`platinum` | `gold` | `silver` | `bronze` | `strategic` | `academic` | `government`

## Key Interfaces
- **CompanyPartnership** — Company with tier, contact info, hiring stats, status
- **CompanyPartnershipTier** — 7-tier classification system

## Statuses
`active` | `inactive` | `suspended`

## Key Metrics
- totalHires, totalInternshipsOffered, totalPlacementDrives

## Pages
- CompanyPartnerships — Partner registry with tier tabs, search, grid layout
