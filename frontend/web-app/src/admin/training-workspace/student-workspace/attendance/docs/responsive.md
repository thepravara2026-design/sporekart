# Attendance Platform — Responsive Design

## Breakpoints

| Breakpoint | Layout |
|------------|--------|
| ≥1024px | Multi-column grids, full table, inline search/filter |
| 768–1023px | 2-column grids, card view preferred |
| 320–767px | Single column, stacked panels, horizontal scroll on table |

## Component Behavior

- **Dashboard**: 6 widgets in responsive grid (6→3→1 columns)
- **Register**: Table scrolls horizontally on mobile; card view is default for small screens
- **Calendar**: 7-column grid compresses with smaller cell sizes; legend wraps
- **Analytics**: 2-column course/monthly section stacks vertically
- **Policies**: Cards go from 2-column to single column
- **Sub-nav tabs**: Wrap to multiple rows on mobile
- **All**: No horizontal page scrolling, 320px minimum supported
