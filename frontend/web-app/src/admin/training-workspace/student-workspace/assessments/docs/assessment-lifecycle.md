# Assessment Lifecycle

## Workflow Stages

```
Assessment Created
       ↓
   Draft Saved
       ↓
   Published
       ↓
   Scheduled
       ↓
 Student Attempts
       ↓
   Submission
       ↓
   Evaluation
       ↓
Results Generated
       ↓
Certificate Eligibility
```

## Status Transition Map

- **draft** → **published** → **scheduled** → **open** → **active** → **paused** (optional)
- **active** → **completed** → **under-evaluation** → **evaluated**
- **evaluated** → **archived** (optional)
- Any status → **cancelled** (except evaluated)
