# Examination Management Architecture

## Exam Sessions

| Concept | Description |
|---------|-------------|
| Assessment Window | Availability start/end date range |
| Duration | Fixed time limit in minutes |
| Attempt Limit | Max attempts per student (1-3) |
| Evaluation Method | Auto-graded, manual, hybrid, or AI |

## Exam States

- **Scheduled** — Future exam, not yet open
- **Published** — Visible to students, not yet active
- **Open** — Available for student access
- **Active** — Student currently attempting
- **Paused** — Temporarily halted by instructor
- **Completed** — All submissions collected
