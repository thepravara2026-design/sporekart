# Assessment Platform — Responsive Design

## Breakpoints

| Breakpoint | Layout |
|------------|--------|
| ≥1024px | Multi-column grids, full table, inline search/filter |
| 768–1023px | 2-column grids, card view preferred |
| 320–767px | Single column, stacked panels, horizontal scroll on table |

## Component Behavior

- **Dashboard**: 8 widgets in responsive grid (8→4→2→1 columns)
- **Registry**: Table scrolls horizontally on mobile; card view is default for small screens
- **Builder**: Template cards go from 6-column to 2-column to single column
- **Question Bank**: 3-column category grid → 2-column → single column
- **Examination Center**: Sections stack vertically with responsive cards
- **Results**: Cards stack vertically, stats grid collapses
- **Analytics**: 2-column course/batch section stacks vertically
- **All**: No horizontal page scrolling, 320px minimum supported
