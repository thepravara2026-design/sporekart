# Evaluation Workflow Design

## Evaluation Methods

| Method | Description | Use Case |
|--------|-------------|----------|
| Auto-graded | Instant scoring for objective types | Quizzes, Objective Tests |
| Manual-graded | Instructor evaluates responses | Essays, Practical Tasks |
| Hybrid | Auto + manual combined | Mixed-format assessments |
| AI Evaluated | Future AI-assisted grading | All types (future) |

## Scoring Model

| Component | Description |
|-----------|-------------|
| Maximum Marks | Total possible score |
| Passing Marks | Minimum to pass |
| Scored Marks | Actual student score |
| Percentage | Scored/Max × 100 |
| Grade | A/B/C/D/F letter grade |
| Performance Band | Excellent/Good/Average/Below Average/Poor |
| Competency Level | Novice/Beginner/Competent/Proficient/Expert |

## Grade Scale

| Score Range | Grade | Performance Band | Competency Level |
|-------------|-------|------------------|------------------|
| 85-100% | A | Excellent | Expert |
| 70-84% | B | Good | Proficient |
| 55-69% | C | Average | Competent |
| 40-54% | D | Below Average | Beginner |
| 0-39% | F | Poor | Novice |
