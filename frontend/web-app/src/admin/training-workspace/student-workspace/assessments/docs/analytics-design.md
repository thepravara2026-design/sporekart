# Assessment Analytics Design

## Dashboard Widgets

| Widget | Source | Purpose |
|--------|--------|---------|
| Total Assessments | Assessment count | Overall volume |
| Upcoming Assessments | Filtered by scheduled/published/open | Pipeline view |
| Completed Assessments | Filtered by completed/evaluated | Delivery tracking |
| Average Score | Result percentages | Overall performance |
| Highest Score | Max percentage | Best performer |
| Lowest Score | Min percentage | Areas needing attention |
| Pass % | Pass/fail ratio | Success rate |
| Fail % | Fail ratio | Improvement areas |

## Analytics Sections

### Course Performance
Average score per course, color-coded (green ≥70%, amber ≥50%, red <50%)

### Batch Performance
Average score per batch, same color coding

### Question Difficulty Distribution
Bar chart showing Beginner/Intermediate/Advanced/Expert question counts

### Monthly Trend
Column chart showing assessment count per month
