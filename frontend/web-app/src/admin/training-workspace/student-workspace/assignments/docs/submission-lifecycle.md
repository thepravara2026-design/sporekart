# Submission Lifecycle

## Workflow Stages

```
Assignment Published
       ↓
  Student Opens
       ↓
  Work Started
       ↓
  Draft Saved (placeholder)
       ↓
   Submission
       ↓
  Review Queue
       ↓
  Evaluation (placeholder)
       ↓
    Feedback
       ↓
   Completed
```

## Submission Status Transition

1. **not-started** — Initial state when assignment is published
2. **draft** — Student has saved work-in-progress
3. **submitted** — Work submitted before deadline
4. **late** — Work submitted after deadline
5. **under-review** — Submission assigned to evaluator
6. **reviewed** — Evaluation completed, feedback provided
7. **resubmitted** — Revised version submitted (future)
8. **accepted** — Final acceptance
9. **rejected** — Failed to meet minimum criteria
