### Known Firefox Limitation

**Firefox local launch hangs** in the Windows test environment (browsers installed: firefox-1532). This is a documented environment limitation, not an application defect. The CI workflow (`playwright-regression.yml`) installs and runs Firefox successfully in the Ubuntu CI environment.

### Mitigation

- CI pipeline: `npx playwright install --with-deps chromium firefox webkit`
- Six browser projects configured in `playwright.config.ts`
- Artifact uploads per project (HTML report, JSON, JUnit, traces, videos, screenshots)
- Retry logic: 2 retries in CI, 1 locally
