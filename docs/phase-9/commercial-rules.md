# Commercial Rules Framework

## Rule Types

| Type | Description | Example |
|------|-------------|---------|
| min_price | Minimum allowable price | ₹10 minimum for fresh produce |
| max_price | Maximum allowable price | ₹2000 max for premium rice |
| suggested_price | Recommended selling price | ₹699 suggested for mushroom kits |
| margin | Minimum margin requirement | 15% margin on value-added products |
| cost | Maximum cost price | ₹500 max cost for training materials |
| approval | Approval required flag | Price changes >10% need manager approval |

## Applicability

Rules can target: all products, specific categories, brands, products, collections, or customer segments.

## Future

Integration with inventory, order, and financial systems for automated rule enforcement and exception handling.
