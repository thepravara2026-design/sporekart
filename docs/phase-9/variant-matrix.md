# Variant Matrix

## Purpose

Enterprise-grade matrix view that displays all variants of a product in a tabular format with dynamic attribute columns.

## Features

- Dynamic column generation from variant attributes
- SKU display with monospace formatting
- Price and stock visibility
- Status badges for quick scanning
- Row selection for detail view
- Hover highlighting for readability
- Responsive horizontal scroll for many attributes

## Comparison View

Side-by-side hero comparison with:
- Multi-variant selection via toggle buttons
- Attribute-by-attribute comparison rows
- Price, stock, and status comparison
- Difference highlighting (future)

## Use Cases

- Quick overview of all variants
- Identify gaps in variant coverage
- Compare pricing across variants
- Audit attribute consistency
- Bulk selection for operations
