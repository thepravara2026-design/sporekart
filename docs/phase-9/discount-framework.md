# Discount Framework

## Discount Types

| Type | Description |
|------|-------------|
| Percentage | % off selling price |
| Fixed | Fixed amount discount |
| Volume | Quantity-based discount |
| Wholesale | Bulk purchase discount |
| Coupon | Coupon code placeholder |

## Properties

- Condition-based (min amount, min/max quantity)
- Stackable (multiple discounts can combine)
- Priority ordered (higher priority wins)
- Time-bound with start/end dates
- Status workflow: draft → scheduled → active → expired → archived

## Promotional Pricing

8 campaign types: campaign, limited_time, weekend, seasonal, featured, collection, category, brand, and launch.
