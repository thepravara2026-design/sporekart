# Scheduled Pricing

## Schedule Types

| Type | Description | Duration |
|------|-------------|----------|
| Campaign | Marketing campaign pricing | Campaign period |
| Seasonal | Season-based pricing (summer, monsoon, harvest) | 3 months |
| Limited Time | Short-duration promotions | Days to weeks |
| Flash Sale | Very short high-discount events | 24-72 hours |
| Weekend Offer | Recurring weekend pricing | Fri-Sun |
| Festival | Holiday/special event pricing | Event period |
| Launch | New product introductory pricing | ~30 days |

## Features

- Status workflow: draft → scheduled → active → expired → cancelled
- Priority ordering for overlapping schedules
- Campaign name association
- Entity targeting (product, category, brand, collection)
- Per-tier price overrides
- Preview, edit, duplicate, activate, cancel actions

## Future

Automation integration with inventory levels, demand forecasting, and competitor price monitoring.
