# Attribute Management

## Attribute Types

| Type | Description | Example |
|------|-------------|---------|
| text | Free text value | "Includes full nutrient set" |
| number | Numeric value | 42 |
| select | Predefined options | [Beginner, Standard, Premium] |
| boolean | True/false | Organic: Yes |
| dimension | Length/width/height | 40×30×15 cm |
| weight | Weight value | 200 g |

## Attribute Groups

- General (weight, size, kit type, difficulty)
- Agriculture (organic, grade, cultivation method, yield)
- Packaging (package type, material)
- Storage (shelf life, storage instructions)
- Technical (plants capacity, warranty)
- Marketing (what's included)

## Features

- Reusable attribute definitions across products
- Filterable and comparable flagging
- Required attribute enforcement
- Description support
- Display order configuration
- Group-based organization

## Future

Dynamic custom attributes created by administrators, attribute inheritance in variant hierarchies.
