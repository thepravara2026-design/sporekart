# Packaging Management

## Packaging Architecture

Two-tier hierarchy: Primary (consumer-facing) and Master Carton (logistics).

## Packaging Types

| Type | Example |
|------|---------|
| Pouch | Dried mushroom packaging |
| Bag | Bulk mushroom, spawn bags |
| Box | Hydroponic kit box |
| Tray | Fresh mushroom tray |
| Carton | Master shipping carton |

## Properties

- **Dimensions**: Length × Width × Height (cm/mm/in)
- **Weight**: Net weight with unit (g/kg/lb)
- **Volume**: Cubic capacity (L/ml)
- **Material**: PET Plastic, LDPE, Aluminium Foil, Corrugated Cardboard, etc.
- **Storage Instructions**: Temperature, humidity, handling requirements
- **Handling Instructions**: Special handling notes
- **Primary/Secondary/Master**: Packaging hierarchy level
