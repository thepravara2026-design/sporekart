# DDR-005: Responsive Strategy — 6 Breakpoints + Drawer/Rail/Fluid

## Status
Accepted

## Date
2026-07-13

## Decision Makers
- Chief Design Officer
- Principal UX Architect
- Principal Design System Architect
- Principal Frontend Architect

## Problem
Define a responsive strategy that works across 375px–1536px+ with a single codebase, consistent mental model, and optimal UX per device class.

## Context
- Primary: Low-end Android (375px, 1.6Mbps 4G)
- Secondary: Tablet (768px portrait, 1024px landscape)
- Tertiary: Laptop (1024px–1279px)
- Primary Desktop: 1280px–1535px
- Large Desktop: 1536px+
- Must share IA with future Android/iOS apps

## Decision

### 1. Breakpoint Tokens

| Token | Value | Device Class |
|-------|-------|--------------|
| `bp-xs` | 480px | Mobile landscape / small phone |
| `bp-sm` | 640px | Large mobile / small tablet |
| `bp-md` | 768px | Tablet portrait |
| `bp-lg` | 1024px | Tablet landscape / Laptop |
| `bp-xl` | 1280px | Desktop |
| `bp-2xl` | 1536px | Wide desktop / Ultra-wide |

### 2. Layout Adaptation

| Region | xs/sm (<768) | md (768–1023) | lg (1024–1279) | xl/2xl (≥1280) |
|--------|--------------|---------------|----------------|----------------|
| **Sidebar** | Drawer (280px, overlay) | Icon Rail (72px, hover expand) | Icon Rail (72px, hover expand) | Fixed 264px |
| **Header Search** | Hidden (Cmd+K only) | Hidden (Cmd+K only) | Hidden (Cmd+K only) | Centered 420px |
| **Content Max-Width** | 100% (prose 100%) | 100% (prose 720px) | 1200px | 1200px (prose) / 1400px (data) |
| **Header Height** | 56px | 56px | 56px | 56px |
| **Page Padding** | 16px | 20px | 24px | 24px |

### 3. Component Adaptation

| Component | xs/sm | md | lg+ |
|-----------|-------|-----|-----|
| **Table** | Card stack (label-value pairs) | Horizontal scroll + sticky first col | Full table, sticky header, sticky first col |
| **DataGrid** | Card stack | 2-col grid | 4–5 col grid |
| **Card Grid** | 1-col | 2-col | 3–4 col |
| **Form** | Stacked (100% inputs) | 2-col for related pairs | 2–3 col |
| **Modal** | Full-screen (bottom sheet) | Centered (max 560px) | Centered (max 560px) |
| **Drawer** | Full-screen bottom sheet | Side sheet (320px) | Side panel (320px) |
| **Toast** | Bottom stack | Top-right stack | Top-right stack |
| **Dropdown** | Full-width bottom sheet | Popover (anchor) | Popover (anchor) |
| **Date Picker** | Full-screen calendar | Popover calendar | Popover calendar |
| **Tabs** | Scrollable (scroll-x) | Fixed (fit) | Fixed (fit) |
| **Pagination** | Prev/Next + Page Input | Full pagination | Full pagination |

### 4. Typography Scaling

| Token | xs/sm | md | lg | xl/2xl |
|---------|-------|----|-----|--------|
| `text-display` | `clamp(2rem, 1.5rem + 3vw, 2.5rem)` | — | — | 3.05rem |
| `text-h1` | `clamp(1.75rem, 1.5rem + 2vw, 2.25rem)` | — | — | 2.44rem |
| `text-h2` | `clamp(1.375rem, 1.25rem + 1vw, 1.75rem)` | — | — | 1.95rem |
| `text-body` | `1rem` | `1rem` | `1rem` | `1rem` |

### 4. Spacing Scale (Responsive)

| Token | xs/sm | md | lg+ |
|-------|-------|----|-----|
| `space-page-x` | 16px | 20px | 24px |
| `space-section-gap` | 24px | 28px | 32px |
| `space-component-gap` | 12px | 14px | 16px |

### 5. Touch Targets

| Breakpoint | Minimum |
|------------|---------|
| xs/sm | 48×48px |
| md+ | 44×44px (desktop precision) |

### 5. Navigation Adaptation (Per DDR-002)

| Breakpoint | Sidebar | Command Palette |
|------------|---------|-----------------|
| xs/sm | Drawer (swipe + hamburger) | Full-screen |
| md | Icon rail (hover expand) | Centered modal |
| lg+ | Fixed sidebar | Centered modal |

## Alternatives Considered

| Option | Rejected Because |
|--------|------------------|
| 4 breakpoints (Bootstrap) | Too coarse; tablet landscape needs distinct treatment |
| 8 breakpoints (Tailwind default) | Too many; maintenance burden; diminishing returns |
| Container queries only | Browser support incomplete; fallback complexity |
| Fixed layouts per breakpoint | Maintenance nightmare; not future-proof |

## Consequences

### Positive
- Single mental model across all devices
- Sidebar → Icon Rail → Drawer pattern scales elegantly
- Command Palette works everywhere (progressive enhancement)
- Tables → Cards on mobile preserves data access
- Fluid typography via `clamp()` — no breakpoint jumps

### Negative
- More CSS complexity (mitigated by token-driven CSS)
- Icon rail on tablet requires hover/focus expansion (touch + keyboard)
- Drawer on mobile adds tap (mitigated by persistent workspace switcher in header)

### Risks
- **Tablet hover:** Touch devices don't hover → Must support tap-to-expand + click-outside-close
- **Table card stack:** Complex tables → Consider horizontal scroll as fallback
- **Icon rail labels:** Truncation at 72px → Tooltip on hover/focus

## Implementation

### CSS Structure
```css
/* Tokens */
:root {
  --bp-xs: 480px;
  --bp-sm: 640px;
  --bp-md: 768px;
  --bp-lg: 1024px;
  --bp-xl: 1280px;
  --bp-2xl: 1536px;
}

/* Container Queries for Components */
@container (min-width: 480px) { /* sm */ }
@container (min-width: 768px) { /* md */ }

/* Media Queries for Layout */
@media (max-width: 767px) { /* xs/sm: drawer */ }
@media (min-width: 768px) and (max-width: 1023px) { /* md: icon rail */ }
@media (min-width: 1024px) { /* lg+: fixed sidebar */ }
```

### Sidebar Implementation
```tsx
// ResponsiveSidebar.tsx
const isMobile = useMediaQuery('(max-width: 767px)');
const isTablet = useMediaQuery('(min-width: 768px) and (max-width: 1023px)');

return isMobile ? <Drawer /> : isTablet ? <IconRail /> : <FixedSidebar />;
```

### Container Queries for Components
```css
/* Card Grid */
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: var(--space-component-gap);
}

/* Table → Card Stack */
@container (max-width: 767px) {
  .table-responsive thead { display: none; }
  .table-responsive tbody tr { display: block; margin-bottom: 16px; }
  .table-responsive td { display: flex; justify-content: space-between; padding: 8px 0; }
  .table-responsive td::before { content: attr(data-label); font-weight: 500; color: var(--color-text-secondary); }
}
```
