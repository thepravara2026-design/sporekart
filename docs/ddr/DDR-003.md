# DDR-003: Typography System — System Stack + Modular Scale

## Status
Accepted

## Date
2026-07-13

## Decision Makers
- Chief Design Officer
- Principal Visual Designer
- Principal Design System Architect
- Principal Frontend Architect

## Problem
Define a typography system that is performant, accessible, readable across devices and literacy levels, and maintainable at scale.

## Context
- Primary audience: Indian farmers (varying literacy, low-end Android)
- Secondary: Enterprise admins (desktop, high-DPI)
- Must support Devanagari (Hindi/Marathi) + Latin
- Zero font download on first load (performance)
- Single font family for coherence; mono for data

## Decision
**Primary Font Stack:** System UI Stack (zero download, perfect OS integration, full script support)
**Monospace Font Stack:** System Mono Stack (data, codes, OTP)
**Scale:** Modular 1.25 ratio (major third) from 16px base
**Responsive:** Fluid `clamp()` for display sizes; fixed `rem` for semantic sizes

### Font Stacks

```css
--font-family-sans: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
--font-family-mono: ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, "Liberation Mono", monospace;
```

**Future Brand Font Slot:** `--font-family-brand: "Inter", var(--font-family-sans);` (Part 1E+)

### Responsive Scaling Strategy

```css
/* Display sizes: fluid clamp() */
--text-display: clamp(2.44rem, 2rem + 2vw, 3.05rem);
--text-h1: clamp(1.95rem, 1.75rem + 1vw, 2.44rem);
--text-h2: clamp(1.56rem, 1.38rem + 0.9vw, 1.95rem);
--text-h3: clamp(1.25rem, 1.13rem + 0.6vw, 1.56rem);

/* Semantic sizes: fixed rem (user zoom respects) */
--text-body: 1rem;
--text-body-sm: 0.875rem;
/* ... */

/* Media query overrides only for display sizes if clamp insufficient */
@media (min-width: 1280px) {
  :root { --text-h1: 2.44rem; }
}
@media (max-width: 640px) {
  :root { --text-h1: 1.95rem; }
}
```

### Numeric Formatting

## Alternatives Considered

| Alternative | Pros | Cons | Why Rejected |
|-------------|------|------|--------------|
| **Inter (self-hosted)** | Distinctive brand; great readability | 50KB+ download; extra request; CSP complexity | Performance budget |
| **Roboto + Noto Sans Devanagari** | Good Devanagari | Two fonts; 60KB+; licensing | System stack covers both |
| **Variable Font (Inter VF)** | Single file; all weights | 45KB; browser support gaps | System stack = 0KB |
| **1.333 Scale (Perfect Fourth)** | Classic | Larger jumps; less granular | 1.25 = more granular |
| **1.2 Scale (Minor Third)** | Subtle | Too many steps; hard to distinguishable | 1.25 = sweet spot |

## Consequences

### Positive
- **Zero font download** — Instant text render; no CLS from fonts
- **Perfect Devanagari** — System fonts include Noto on Android, Apple on iOS
- **Performance** — Zero font bytes; no preload needed
- **Accessibility** — Respects user font size; system font scaling
- **Maintenance** — No font files to update; OS updates = free improvements
- **Consistency** — Single scale, single family; no "which font?" decisions

### Negative
- **Brand distinctiveness** — Looks like system UI (mitigated by color/spacing/illustrations)
- **Weight granularity** — System fonts typically 400/500/600/700 only (no 300/800)
- **Kerning control** — Limited vs. variable font

### Risks
- **Android fragmentation** — Some OEMs substitute fonts → Test on Samsung/Xiaomi/Stock
- **Devanagari line height** — May need `line-height: 1.7` for Hindi body → Token override
- **Future brand font** — Slot reserved; migration path documented

## Implementation

```css
:root {
  /* Families */
  --font-family-sans: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
  --font-family-mono: ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, "Liberation Mono", monospace;
  --font-family-brand: var(--font-family-sans); /* reserved */

  /* Scale */
  --text-display: clamp(2.44rem, 2rem + 2vw, 3.05rem);
  --text-h1: clamp(1.95rem, 1.75rem + 1vw, 2.44rem);
  --text-h2: clamp(1.56rem, 1.38rem + 0.9vw, 1.95rem);
  --text-h3: clamp(1.25rem, 1.13rem + 0.6vw, 1.56rem);
  --text-h4: 1.25rem;
  --text-h5: 1.125rem;
  --text-h6: 1rem;
  --text-subtitle: 1rem;
  --text-body-lg: 1.125rem;
  --text-body: 1rem;
  --text-body-sm: 0.875rem;
  --text-caption: 0.8125rem;
  --text-label: 0.8125rem;
  --text-button: 0.875rem;
  --text-table: 0.875rem;
  --text-table-h: 0.75rem;
  --text-code: 0.875rem;
  --text-numeric: 1rem;
  --text-otp: 2rem;

  /* Weights */
  --weight-normal: 400;
  --weight-medium: 500;
  --weight-semibold: 600;
  --weight-bold: 700;

  /* Line Heights */
  --leading-tight: 1.15;
  --leading-snug: 1.25;
  --leading-normal: 1.35;
  --leading-relaxed: 1.5;
  --leading-loose: 1.6;

  /* Tracking */
  --tracking-tight: -0.02em;
  --tracking-snug: -0.01em;
  --tracking-normal: 0;
  --tracking-wide: 0.02em;
  --tracking-wider: 0.05em;
  --tracking-otp: 0.25em;
}

/* Component Mapping */
h1 { font: var(--weight-bold) var(--text-h1)/var(--leading-tight) var(--font-family-sans); letter-spacing: var(--tracking-tight); }
h2 { font: var(--weight-semibold) var(--text-h2)/var(--leading-snug) var(--font-family-sans); letter-spacing: var(--tracking-snug); }
h3 { font: var(--weight-semibold) var(--text-h3)/var(--leading-normal) var(--font-family-sans); }
h4 { font: var(--weight-semibold) var(--text-h4)/var(--leading-normal) var(--font-family-sans); }
body { font: var(--weight-normal) var(--text-body)/var(--leading-relaxed) var(--font-family-sans); }
.label { font: var(--weight-medium) var(--text-label)/var(--leading-normal) var(--font-family-sans); letter-spacing: var(--tracking-wide); }
.button { font: var(--weight-semibold) var(--text-button)/var(--leading-normal) var(--font-family-sans); letter-spacing: var(--tracking-wide); }
.table th { font: var(--weight-semibold) var(--text-table-h)/var(--leading-normal) var(--font-family-sans); letter-spacing: var(--tracking-wider); text-transform: uppercase; }
.table td { font: var(--weight-normal) var(--text-table)/var(--leading-relaxed) var(--font-family-sans); }
.numeric { font: var(--weight-medium) var(--text-numeric)/var(--leading-relaxed) var(--font-family-mono); font-variant-numeric: tabular-nums lining-nums; }
.otp-input { font: var(--weight-semibold) var(--text-otp)/var(--leading-tight) var(--font-family-mono); letter-spacing: var(--tracking-otp); }
```
