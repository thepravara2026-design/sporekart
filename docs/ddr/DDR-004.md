# DDR-004: Color System — Green Primary + Semantic Aliases

## Status
Accepted

## Date
2026-07-13

## Decision Makers
- Chief Design Officer
- Principal Design System Architect
- Principal Visual Designer

## Problem
Define a color system that:
- Expresses agricultural/scientific brand identity
- Meets WCAG 2.2 AA contrast for all semantic uses
- Supports dark mode and high contrast
- Enables data visualization (categorical, sequential, diverging)
- Is maintainable via token architecture

## Context
- Brand color: Agricultural green (trust, growth, science)
- Must work for Indian users (low-end Android, bright sun, low literacy)
- Data-heavy product (analytics, governance, analytics) needs robust data viz palette
- Token architecture: Primitive scales → Semantic aliases → Component tokens

## Decision

### 1. Primitive Scales (50–950)

| Hue | Scale | Key Values |
|-----|-------|------------|
| **Green (Primary)** | 50–950 | 600 `#2F6F4F` (Primary), 700 `#265D3F` (Hover), 800 `#1E4D33` (Pressed) |
| **Neutral (Warm Stone)** | 50–950 | 100 `#F7F8F7` (Bg), 200 `#E3E6E3` (Border), 900 `#1D2B22` (Text) |
| **Success** | 50–700 | 600 `#2E7D32` |
| **Warning** | 50–700 | 600 `#F57F17` |
| **Danger** | 50–700 | 600 `#C62828` |
| **Info** | 50–700 | 600 `#1565C0` |

### 3. Data Visualization Palettes

**Categorical (Colorblind-Safe, 8 colors):**
1. `#2F6F4F` (Primary Green)
2. `#1565C0` (Info Blue)
3. `#F57F17` (Warning Amber)
4. `#C62828` (Danger Red)
5. `#6A1B9A` (Deep Purple)
6. `#00838F` (Teal)
7. `#E65100` (Deep Orange)
8. `#33691E` (Dark Green)

**Sequential (Heatmaps):**
`green-50 → green-900` (single hue, luminance steps)

**Diverging:**
`blue-50 → neutral-100 → red-50` (center = neutral)

### 5. High Contrast (Forced Colors)
- Use system colors exclusively (`Canvas`, `CanvasText`, `Highlight`, etc.)
- No custom hex in `@media (forced-colors: active)`
- Focus: 3px solid `CanvasText`

## Alternatives Considered

| Option | Rejected Because |
|--------|------------------|
| Blue Primary | Doesn't communicate agriculture/nature |
| Orange/Red Primary | Too aggressive; doesn't convey trust/growth |
| Multi-brand colors | Dilutes brand; increases cognitive load |
| Flat color (no scales) | No hover/pressed/disabled states; no dark mode |

## Consequences

### Positive
- **Scientific credibility** — Green = life, growth, data
- **Accessibility** — All semantic pairs meet 4.5:1 (text) / 3:1 (UI)
- **Dark mode ready** — Semantic aliases swap cleanly
- **Data viz ready** — Categorical palette tested for colorblind safety
- **Maintainable** — Primitive → Semantic → Component layer

### Negative
- **Green fatigue** — Risk of monotony (mitigated by semantic neutrals + data viz palette)
- **Green on green** — Avoid green text on green bg (use `color-text-on-primary`)
