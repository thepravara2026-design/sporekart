## DDR Template

For new decisions, use the template in `/docs/ui/documentation-standards.md`

## Naming Convention

`DDR-XXX.md` where XXX is sequential 3-digit number.

## Status Values

- **Proposed** — Under discussion
- **Accepted** — Approved and implemented
- **Superseded** — Replaced by newer DDR
- **Deprecated** — No longer applicable

---

## Governance

- **Owner:** Principal Design System Architect
- **Review:** Quarterly (or on major version)
- **Archive:** Superseded/Deprecated DDRs moved to `/archive`
