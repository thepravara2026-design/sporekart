# Alert Engine Design

## Purpose
Generates business, operational, performance, security, and maintenance alerts for 15 monitored domains.

## Alert Categories
| Category | Examples | Seeds |
|---|---|---|
| BUSINESS | Revenue Anomaly, Churn Risk, Cancellation Rate | 5 |
| OPERATIONAL | Order Delay, Warehouse Capacity, Inactive Vendors | 5 |
| PERFORMANCE | API Latency, DB Pool Exhaustion, Memory Usage | 3 |
| SECURITY | Failed Login Spike, Suspicious API Access | 2 |
| MAINTENANCE | SSL Expiry, Backup Failure | 2 |

## Alert Lifecycle
1. **OPEN** — Alert generated by engine
2. **ACKNOWLEDGED** — Operator acknowledges
3. **RESOLVED** — Issue resolved

## Key Methods
- `generateAllAlerts()` — Generates 10+ alerts across all categories
- `generateAlertsForCategory(category)` — Generates alerts for a specific category
- `generateRisksForCategory(category)` — Generates risks for a specific category
