# Phase 3 Context Map

## Core contexts

- Customer Commerce Context
- Identity Context
- Inventory Context
- Order Context
- Payment Context
- Fulfillment Context
- Notification Context

## Expansion contexts

- Marketplace Context
- Enterprise Commerce Context
- Intelligence Context
- Mobility Context
- Governance Context

## Context relationships

- Marketplace Context consumes Catalog, Inventory, Order, Payment, and Fulfillment.
- Enterprise Commerce Context consumes Catalog, Order, CRM, and ERP integration services.
- Intelligence Context consumes events and read models from Catalog, Order, Content, and Analytics.
- Mobility Context consumes Identity, Cart, Order, and Notification services.
- Governance Context protects partner and enterprise workflows through Identity and Policy services.
