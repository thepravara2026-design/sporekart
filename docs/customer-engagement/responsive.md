# Responsive Adaptations

The engagement workspace adjusts to different screen sizes.

## Responsive Guidelines

- **Desktop (>= 1024px)**:
  - 4-column product grids.
  - Side-by-side loyalty and referral cards.
- **Tablet (768px - 1023px)**:
  - Grids resize to 2-column or 3-column structures.
  - Search inputs and sorting boxes align beside filters.
- **Mobile (< 768px)**:
  - All grids stack into a single column.
  - Tabs wrap to multiple lines automatically.
  - Click targets are sized to >= 44x44px.
  - Sideboards stack vertically.
