# Saved for Later Design

The Saved for Later tab manages items deferred during checkout.

## Layout & Features

- **Split List Layout**: Renders products in a horizontal list block.
- **Price Alerts**: Displays warnings when prices drop below original amounts (e.g. "Price dropped by ₹50 since you saved it!").
- **Stock Warnings**: Flags low-stock limits (e.g. "Only 3 items remaining!").
- **Actions**: Quick "Move to Cart" button to restore item to the main checkout path, alongside "Delete" to dismiss the item.
