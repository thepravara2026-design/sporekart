# Notification Center

The Notification Center is a central inbox for order updates, training alerts, and system notices.

## Design Details

- **Header counters**: Tracks unread notifications in real time.
- **Mark All Read action**: Instantly clears active unread badges.
- **Categorization filters**: Tabs allow quick filtering (All, Unread, Orders, Training, Promos).
- **Search bar**: Performs instant keyword matches.
- **Feed list**:
  - Styled with high-contrast indicator borders on unread items.
  - Custom color-coded emojis representing warning levels (blue for orders, green for training, orange for price alerts, pink for promotions, grey for system maintenance).
  - Toggles read status on click, and supports a dismiss button to remove notifications.
