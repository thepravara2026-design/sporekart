# Course Catalog Library

The Course Library lists intermediate and advanced mycology courses.

## Features

- **Search & Filters Control Block**:
  - Live query search input box.
  - Category dropdown filter (Lab Work, Cultivation, Commercial).
  - Difficulty level dropdown filter (Beginner, Intermediate, Advanced).
- **Sorting Select**: Sorts by average student rating or total course duration.
- **Card grid layout**:
  - Top header banner displays the course title over gradient colors.
  - Body area maps description text, duration/level icons, and enrollment progress indicators.
