# Flexible Media Containers

Responsive parameters for the learning system.

## Adaptation Guides

- **Desktop (>= 1024px)**:
  - 2-column split video player layouts.
  - 3-column catalog grids.
- **Tablet (768px - 1023px)**:
  - Video split panel collapses into a vertical single stack.
  - Dashboard stats wrap to a 2x2 grid.
- **Mobile (< 768px)**:
  - Sits as a single column.
  - Video maintains aspect ratio (16:9) to prevent letterboxing.
  - Buttons expand to full width.
  - Touch targets are expanded to at least 44x44px.
