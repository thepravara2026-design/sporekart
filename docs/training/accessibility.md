# Accessibility Compliance Audit

Keyboard and screen reader controls inside training platforms.

## Audit Logs

- **Keyboard navigation**:
  - Accordions are expandable using `Enter` or `Space` key actions.
  - Video play controls are keyboard-navigable.
- **ARIA Semantics**:
  - Course progress gauges map correct attributes.
  - Tab controls for video notes define target panels.
- **Motion settings**:
  - CSS animations respect system settings (`prefers-reduced-motion`).
