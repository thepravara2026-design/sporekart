# Printable Certificates

This page hosts verifiable certificates earned by growers.

## Features

- **Certification Cards**: Bordered frames with completion timestamps, verification codes, and course names.
- **PDF Generation**: Exposes triggers to simulate high-resolution PDF certificate downloads.
- **QR Code Verification**: A "Verify" action opens a modal containing a mock QR code and verification path, validating credentials against sporekart database hashes.
