# Video Learning Classroom

The classroom is a split-screen workspace designed to support focused learning.

## Layout Configuration

- **Left Panel (65% width)**:
  - Video Player Interface: Large dark layout, mock play/pause buttons, progress slider, and duration stats.
  - Contextual Tabs: Video Transcript text, a textarea to log notes, and list of downloadable worksheets/PDFs.
- **Right Panel (35% width)**:
  - Curriculum list displaying checkmark indicators next to finished lessons. Clicking a lesson switches the active video.
- **Milestone Completer**: Exposes a "Mark Lesson Complete" button that updates progress percentages in real time.
