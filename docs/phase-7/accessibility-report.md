# Accessibility Certification Report

WCAG 2.2 AA compliance certification.

## Compliance Metrics

- **Keyboard Loops**: All forms and ticket conversation inputs use standard tab indices.
- **Star Ratings**: Interactive stars include keyboard focus states and clear text alternatives.
- **ARIA Semantics**: Progress bar meters map correct attributes.
- **Reduced motion**: Transition durations adapt when `prefers-reduced-motion` is active.
