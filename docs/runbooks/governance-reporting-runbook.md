# Governance Reporting Runbook

## Health Checks

### API Health Endpoint

```bash
curl -X GET http://localhost:8080/api/v1/governance/analytics/metrics?size=1
```

Expected response (200):
```json
{
  "metrics": [],
  "page": 0,
  "size": 1,
  "totalElements": 0
}
```

### Health Indicators

| Check | Component | Failure Impact |
|-------|-----------|---------------|
| Metric collection | MetricsService | All analytics data stops flowing |
| Metrics aggregation | MetricsAggregator | Aggregated data unavailable |
| KPI calculation | KpiCalculator | KPI values stale |
| Report generation | ReportingService | Reports fail to generate |
| Export engine | ExportService | Export requests fail |
| Redis connectivity | Cache | Dashboard/report cache degraded |
| Database connectivity | JPA | All persistence operations fail |
| Kafka connectivity | Kafka publisher | Analytics events not published |

### Grafana Alerts

| Alert | Condition | Severity | Action |
|-------|-----------|----------|--------|
| PipelineFailure | `analytics_errors_total > 10/min` | CRITICAL | Immediate incident response |
| ReportGenerationFailure | `analytics_report_generation_total{status="FAILED"} > 5/min` | WARNING | Investigate generation pipeline |
| ExportFailure | `analytics_export_total{status="FAILED"} > 3/min` | WARNING | Investigate export engine |
| CacheHitLow | `analytics_cache_hit_ratio < 0.50` | INFO | Review cache TTL config |
| KpiStale | Time since last `kpi.calculated` > 15min | WARNING | Verify KPI calculation schedule |
| AggregationLag | Time since last aggregation > 10min | WARNING | Verify aggregation schedule |
| NoMetricsReceived | `analytics_metrics_collected_total` rate = 0 for 5min | WARNING | Check metric sources |

## Cache Invalidation

### Manual Cache Clear

```bash
# Clear all governance analytics caches
redis-cli KEYS "governance:*" | xargs redis-cli DEL

# Clear specific namespace
redis-cli DEL "governance:metrics:*"
redis-cli DEL "governance:dashboard:*"
redis-cli DEL "governance:kpis:*"
redis-cli DEL "governance:trends:*"
redis-cli DEL "governance:reports:*"
```

### Automatic Invalidation Events

| Event | Cache Invalidated |
|-------|------------------|
| Metric collected | governance:metrics:* (aggregated) |
| Dashboard updated | governance:dashboard:* (specific dashboard) |
| KPI calculated | governance:kpis:* (specific KPI) |
| Trend analyzed | governance:trends:* (specific trend) |
| Report generated | governance:reports:* (report list) |
| Config updated | All governance namespaces |

## Report Generation Troubleshooting

### Issue: Report stuck in PENDING or GENERATING status

**Possible causes:**
1. Data collection timeout — metric query taking too long
2. Template application error — template rendering failure
3. Cache miss forcing full data scan
4. Concurrent report limits reached

**Resolution:**
```bash
# Check report status
curl -s http://localhost:8080/api/v1/governance/analytics/reports?status=PENDING

# Get specific report details
curl -s http://localhost:8080/api/v1/governance/analytics/reports/rpt-abc-123

# Check pipeline configuration
# Verify metric sources are available
# Check logs for template rendering errors
```

### Issue: Report data incomplete or incorrect

**Possible causes:**
1. Metric data missing for the report period
2. Aggregation window misaligned with report period
3. KPI calculation using stale data
4. Template version mismatch

**Resolution:**
```bash
# Verify metric data exists for report period
curl -s "http://localhost:8080/api/v1/governance/analytics/metrics?from=2026-07-11T00:00:00Z&to=2026-07-12T00:00:00Z&size=1"

# Check KPI values
curl -s http://localhost:8080/api/v1/governance/analytics/kpis

# Verify aggregated data
curl -s -X POST http://localhost:8080/api/v1/governance/analytics/aggregate \
  -H "Content-Type: application/json" \
  -d '{
    "aggregation": "COUNT",
    "windowMinutes": 60,
    "from": "2026-07-11T00:00:00Z",
    "to": "2026-07-12T00:00:00Z"
  }'
```

### Issue: Scheduled reports not generating

**Possible causes:**
1. Schedule deactivated — check `is_active` flag
2. Cron expression misconfigured — verify `cron_expression`
3. Scheduler service not running — check logs
4. Next run calculation error — check `next_run_at`

**Resolution:**
```bash
# List active schedules
curl -s http://localhost:8080/api/v1/governance/analytics/schedules

# Check schedule details
curl -s http://localhost:8080/api/v1/governance/analytics/schedules/sch-abc-123

# Verify schedule's last run and next run times
# Check scheduler thread pool configuration
```

### Issue: Report generation takes too long

**Possible causes:**
1. Large time range requiring extensive data aggregation
2. Complex report type (e.g., EXECUTIVE_SUMMARY) aggregating many metrics
3. Database query performance degradation
4. Insufficient aggregation pre-computation

**Resolution:**
```yaml
# Adjust aggregation pre-computation windows
governance:
  analytics:
    aggregation:
      precompute-windows: 5min, 15min, 1h, 6h, 24h, 7d, 30d
    report:
      generation-timeout: 30s
```

## Export Troubleshooting

### Issue: Export stuck in PROCESSING

**Possible causes:**
1. Format conversion error — CSV/JSON serializer failure
2. File system full — check storage capacity
3. Export engine not initialized
4. Report data too large for single export

**Resolution:**
```bash
# Check export status
curl -s http://localhost:8080/api/v1/governance/analytics/exports?status=PROCESSING

# Cancel stuck export (requires AI_ADMINISTRATOR)
curl -X POST http://localhost:8080/api/v1/governance/analytics/exports/exp-abc-123/cancel

# Check available disk space
df -h /var/data/governance/exports
```

### Issue: Export download fails (404)

**Possible causes:**
1. Export file deleted or moved
2. File reference path incorrect
3. Export expired per retention policy
4. Storage backend unavailable

**Resolution:**
```bash
# Verify export record exists
curl -s http://localhost:8080/api/v1/governance/analytics/exports/exp-abc-123

# Check file reference path
# Verify retention policy configuration
# Check storage backend health
```

### Issue: CSV output malformed

**Possible causes:**
1. Special characters in metric values not escaped
2. Inconsistent row lengths
3. Encoding mismatch (UTF-8 vs system default)

**Resolution:**
```yaml
# Configure export options
governance:
  analytics:
    export:
      csv:
        delimiter: ","
        quote-char: "\""
        escape-char: "\\"
        include-header: true
        encoding: UTF-8
```
