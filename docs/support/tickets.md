# Ticket Conversations Timeline

Interactive conversation manager detailing chats with lead specialists.

## Design Highlights

- **Status Toggles**: Allows growers to mark cases resolved or reopen them.
- **Messages Timeline**: Alternating chat bubbles with distinct colors (primary brand color for the customer, slate grey for support agents) and timestamps.
- **Reply Input Form**: Integrates a responsive text input panel at the bottom of the feed that appends message bubbles to the conversation log in state.
- **Metadata Sidebar**: Tracks creation times, last update logs, and file attachment lists.
