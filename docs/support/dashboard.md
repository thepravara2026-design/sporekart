# Support Dashboard Design

The Help Center Dashboard is designed for high accessibility and clarity.

## Sections Details

- **Metrics Cards**: Displays counters for active cases and resolved tickets.
- **Recent Tickets**: Lists recent tickets with status indicators, linking directly to details.
- **Featured Articles**: Highlights popular knowledge base topics.
- **AI Helper**: A visual card preparing growers for future automated live chatbot tools.
- **WhatsApp Support Link**: One-click helpline launcher.
