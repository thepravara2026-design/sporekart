# Flexible Messaging Layouts

Responsive grid specifications for the support platform.

## Breakpoints Guides

- **Desktop (>=1024px)**:
  - 2-column split layout for chat dashboards and article reader panels.
  - Multi-column grids for quick support actions and article filters.
- **Tablet (768px - 1023px)**:
  - Sidebars stack vertically below the chat timeline and article body.
- **Mobile (<768px)**:
  - Chat bubbles expand to 85% width to preserve line width and readability.
  - Input boxes, buttons, and file uploader fields scale to full width.
  - Interactive touch targets are styled to be >= 48x48px.
