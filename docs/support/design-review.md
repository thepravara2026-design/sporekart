# Design QA Certificate

Checklist for SporeKart design tokens and style compliance.

## Checklist

- [x] Typography: Built using system font variables (`var(--text-h3)`, `var(--text-body-sm)`).
- [x] Spacing: Styled with standard padding classes.
- [x] Colors: Theme-compliant buttons and cards. High-contrast texts meet WCAG AAA/AA 4.5:1 ratios.
- [x] Chat UI Geometry: Fixed height layouts prevent layout shifts during timeline updates.
