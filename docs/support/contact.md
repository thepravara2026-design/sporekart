# Ticket Creator Form

Detailed client assistance form designed to collect high-fidelity issue descriptions.

## Form Elements

- **Subject text field**: Captures summary headings.
- **Category dropdown**: Categorizes requests (Lab Tech, Shipping, Cultivation).
- **Priority selects**: Marks low/medium/high urgencies.
- **Description area**: Encourages detailed logs (batch codes, autoclave run times).
- **Contact channels**: Selectable radio inputs (Email, Phone callback, WhatsApp).
- **Drag & drop uploads**: Dashed zone simulating PNG/PDF attachment uploads.
