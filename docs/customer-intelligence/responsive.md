# Responsive Layouts

Grid layouts and charts adaptations for customer intelligence.

## Breakpoints

- **Desktop (>= 1024px)**:
  - 2-column split layout for dashboards and analytics panels.
  - Multi-column grids for products shelves.
- **Tablet (768px - 1023px)**:
  - Analytics columns collapse to a vertical stack.
  - Welcome banner metrics align as a 2x2 grid.
- **Mobile (< 768px)**:
  - Interactive widgets and grids stack vertically.
  - Assistant overlay scales to fit portrait screens.
  - Touch targets are expanded to at least 48x48px.
