# Milestones & Achievements

The Loyalty and Achievement Center manages point balances and vouchers.

## Features

- **Redemption Controls**: Exposes actions to redeem points for store vouchers, updating state balances.
- **Badge grid**: Lists milestones (e.g. Sterility Champion, Volume Cultivator) with unlock statuses and point rewards.
- **Points multipliers**: Notes tier point boosts (e.g. 2.5x multipliers).
