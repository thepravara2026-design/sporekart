# Personalized Home Dashboard

The Grower Home Dashboard is the primary welcome space for authenticated clients.

## Key Sections

- **Dynamic Welcomes**: Displays timed greetings (e.g. Good morning, Good evening).
- **Profile Header**: Highlights loyalty point balances and tier details.
- **Resume Widget**: Renders active lecture resume buttons.
- **Active Orders Card**: Displays shipping progress and estimated arrivals.
- **AI Recommendations Shelf**: Visual cultivars and kits suggestion panels.
