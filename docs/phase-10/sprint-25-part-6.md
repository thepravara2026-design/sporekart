# Sprint 25 Part 6 — Enterprise Inventory Movements, Transfers & Transaction History Platform

## Objective
Build the complete Enterprise Inventory Movements, Transfers & Transaction History Platform. This sprint establishes the movement layer on top of Inventory Items (Part 3), Stock Records (Part 4), and Batches (Part 5), enabling full transaction tracking, warehouse transfers, stock adjustments, goods receipt/issue, and audit trails.

## Scope
- New module: `admin/modules/movement/`
- Reuses certified components from Sprint 24 and Sprint 25 Parts 1–5
- Hard constraints: NO backend/DB/API/calculations/barcode/QR/Purchase Orders/Financial posting
- Mock Mode only — all data generated by `movementMockService.ts`
- Token CSS variables only (`--color-*`, `--radius-*`, `--text-*`, `--space-component-gap`)
- WCAG 2.2 AA compliance
- Responsive 320–1920px
- DO NOT MODIFY: Customer Website, Auth, RBAC, Supabase, DB, Sprint 24, Sprint 25 Parts 1–5, Enterprise Design System

## Domain Model
```
Product / Inventory Item (Parts 3–4)
  ↓
Stock Record / Batch (Parts 4–5)
  ↓
Movement — 17 movement types (receipt, issue, transfer, adjustment, damage, return, quality_hold, inspection, reservation, release, consumption, production_issue, production_receipt, cycle_count_adjustment, manual_adjustment, marketplace_allocation, shipment, manufacturing)
  ↓
Transaction — immutable record of every movement with status, quantity, warehouse, user, timestamps
  ↓
Movement Timeline — ordered event log with status transitions
  ↓
Audit Trail — immutable field-level audit records
```

## Key Features
- 17 movement types covering the full inventory operations spectrum
- 10-status transaction lifecycle (draft → pending → approved → processing → completed / rejected / cancelled / archived / failed_validation / blocked)
- 6 role-based permission levels (viewer, inventory_operator, warehouse_operator, inventory_manager, warehouse_manager, administrator)
- Sortable, paginated, selectable TransactionTable with bulk actions toolbar
- Filterable Movement Timeline with event-type filtering
- Warehouse transfer tracking with source/destination visualization
- Stock adjustments with type (positive/negative/damage/expiry/audit/cycle_count/manual) and quantity difference display
- Goods receipt with accepted/rejected/pending quantity breakdown
- Goods issue with reason and destination tracking
- Full audit trail with field-level old/new value tracking
- Analytics dashboard with 7 KPI cards (total transactions, transfers, receipts, issues, adjustments, pending, completed)
- Validation page with 7 rule checks (passed/warning/failed) and run-validation button
- Settings page with 3 groups of toggle/select/number controls
- FAQ help page with 8 expandable Q&A items
- 14-section workspace sidebar for domain navigation
- 6-tab preview app with desktop/tablet/mobile viewport, light/dark theme, and role selector
