# Shipment Tracking Map

This page tracks in-transit courier shipments.

## Transit Route Map

- Implements a custom SVG canvas depicting the map of India.
- Displays a technical grid pattern background.
- Highlights:
  - SporeHub Warehouse (Origin - Bengaluru) with a pulsing green double circle animation.
  - Customer Address (Destination - HSR Layout) with a pulsing blue double circle animation.
  - An animated route line with a moving dash offset that visually represents packages moving along the route.
- A floating layout card overlays the map showing active tracking status ("In Transit") and location.

## Scan History

- Chronological list of completed scanner check-in milestones.
- Renders dates and details from the Delhivery scanning system.
