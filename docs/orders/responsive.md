# Responsive Adaptations

The order experience adjusts to all screens without horizontal scroll.

## Viewport Adaptations

- **Desktop (>= 1024px)**: 
  - Main/Sidebar 2-column details.
  - 4-column metric grids on dashboard.
- **Tablet (768px - 1023px)**:
  - 2-column metrics wrap to 2x2 grid.
  - Side-by-side blocks stack if needed.
- **Mobile (< 768px)**:
  - All grids stack into a single column.
  - Touch targets expanded to >= 44x44px.
  - Welcome banner CTA buttons scale to full-width.
  - Breadcrumbs collapse to compact trail.
