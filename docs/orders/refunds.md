# Refund Framework

Refund processing is tracked step-by-step to minimize customer anxiety.

## Refund Milestones

1. **Refund Initiated**: Request logged by customer.
2. **Approved**: Support agent / QA check passes photo evidence.
3. **Credited**: Transferred back to original payment method (e.g. via Razorpay).

## Transaction Auditing

- Displays refund amount.
- Displays destination source.
- Displays transaction reference ID (UPI Ref/GPay ID) once credited.
