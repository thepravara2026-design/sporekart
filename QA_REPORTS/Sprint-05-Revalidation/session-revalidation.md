### Cookie Strategy

| Aspect | Implementation |
|---|---|
| Auth session token | Supabase httpOnly cookie (Set-Cookie from Supabase Auth server) |
| Refresh token | Persisted to `localStorage` via `AsyncStorage` adapter (`supabase.ts:65-73`) |
| Access token | In-memory (`_session.access_token`) and from `getSession()` |
| Role metadata | Stored in `user.user_metadata.role` — cryptographically signed by Supabase JWT |

### Token Lifecycle

| Phase | Mechanism |
|---|---|
| Issue | `supabase.auth.signInWithOtp` → OTP verify → session with access_token + refresh_token |
| Refresh | `autoRefreshToken: true` in Supabase client config |
| Expiry | `onAuthStateChange` fires TOKEN_REFRESHED or SIGNED_OUT events |
| Revocation | `signOut()` calls `supabase.auth.signOut()` which revokes refresh token |
