## Key Architecture Changes Verified

1. **`context.ts`** — Replaced `activeRole`/`setActiveRole` with `auth: AuthState` (user, session, loading, isAuthenticated, userRole)
2. **`App.tsx`** — Removed `sessionStorage` auth init; subscribes to `onAuthChange`; derives `AuthState` from Supabase
3. **`RequireAuth.tsx`** — Checks `auth.isAuthenticated` and `auth.userRole` instead of `activeRole`
4. **`SessionPages.tsx` / `VerifyOtpPage.tsx`** — No `sessionStorage` writes
5. **`Header.tsx`** — Removed role switcher; uses `auth.userRole` read-only
6. **`WorkspacePage.tsx`, `Sidebar.tsx`, `CommandPalette.tsx`, `AdminLayout.tsx`, `AdminDashboard.tsx`** — All now use `auth.userRole`
7. **`PaymentGateway.ts`** — Self-contained mock with no external endpoint calls
8. **`CheckoutPage.tsx`** — Order creation, idempotency key, localStorage persistence
9. **`lib/csrf.ts`** — CSRF token generation + `X-CSRF-Token` header
10. **`httpClient.ts`** — CSRF token on all mutating requests
