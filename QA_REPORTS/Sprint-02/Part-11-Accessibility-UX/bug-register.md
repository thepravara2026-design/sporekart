| Field | Value |
|-------|-------|

| **Severity** | Medium |

### BUG-QA-2-003 — Focus Not Trapped in SessionTimeoutWarning Dialog

| Field | Value |
|-------|-------|
| **UX Category** | Keyboard / Focus Management |
| **Severity** | Medium |
| **Priority** | High |
| **Browser** | All (Chromium, Firefox, WebKit) |
| **Device** | All (Desktop, Tablet, Mobile) |
| **WCAG Reference** | 2.1.2 No Keyboard Trap / 2.4.3 Focus Order |
| **Component** | SessionTimeoutWarning Dialog |
| **Expected Result** | When session timeout warning is displayed, focus should be trapped inside the dialog until dismissed; Tab/Shift+Tab should cycle through dialog elements only |
| **Actual Result** | Focus remains on background content and is not trapped inside the dialog overlay |
| **User Impact** | Keyboard user can tab behind dialog, losing context; may inadvertently interact with background elements |
| **Business Impact** | Session timeout dialog may not be noticed; risk of data loss; WCAG non-compliance |
| **Evidence** | Defect Summary (Sprint-02/Reports/DEFECT_SUMMARY.md) |
