## Critical Defects

**File:** `frontend/web-app/src/App.tsx:433-441`
**Description:** Auth state is derived from sessionStorage, not from real JWT/Supabase session. Any code can set `sk_session_role` to 'administrator' to gain full access.

**Description:** RequireAuth component checks context role, not actual JWT validity. Expired or forged tokens are not detected.
**Severity:** CRITICAL (Production Blocker)
