# Timeline Operations

## Purpose
Provides a chronological event timeline for audit, monitoring, and root cause analysis.

## Event Severity Colors
| Severity | Color |
|---|---|
| CRITICAL | Red (#dc2626) |
| HIGH | Orange (#ea580c) |
| MEDIUM | Yellow (#ca8a04) |
| LOW | Blue (#2563eb) |
| INFO | Gray (#6b7280) |

## Event Types & Sources
| Type | Source Engine |
|---|---|
| BUSINESS | AlertEngine |
| ALERT | AlertEngine |
| RISK | RiskEngine |
| PLATFORM | AnomalyEngine |
| AI | AnomalyEngine |
| WORKFLOW | AlertEngine |
| TRAINING | AlertEngine |
| INVENTORY | AnomalyEngine |
| MARKETPLACE | AlertEngine |

## Timeline View Features
- Vertical timeline layout with alternating left/right cards
- Severity-based color coding on event nodes
- Type badges with labels
- Source engine identification
- Timestamp display (ISO format)
