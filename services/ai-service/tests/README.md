# Tests

This directory contains test plans and test configuration.

## Test Types

- **Unit Tests** — `src/test/java/com/sporekart/ai/`
- **Integration Tests** — `src/test/java/com/sporekart/ai/`
- **Architecture Tests** — `src/test/java/com/sporekart/ai/architecture/`
- **Performance Tests** — JUnit performance benchmarks
- **Security Tests** — Security compliance tests

## Running Tests

```bash
mvn test
```
